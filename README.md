# Swipe Right Cleaning LLC Website

Responsive static website for a commercial and office cleaning business serving Plano and surrounding North Dallas communities.

## Pages

- `index.html` — home page, services, quote form, contact information
- `booking.html` — Google Calendar cleaning-walkthrough booking page

## Main files

- `styles.css` — site design and responsive layout
- `script.js` — mobile navigation, quote form, square-footage logic, and Calendar embed
- `BOOKING-SETUP.txt` — exact Google Calendar appointment-schedule setup instructions
- `START-HERE.txt` — preview and publishing guide
- `assets/` — logo, favicon, and website photos

## Quote form behavior

Customers can provide either exact square footage or an estimated range. The form creates a prepared email addressed to `quotes@swiperightcleaningllc.com`.

## Calendar setup

The Google Calendar appointment booking page is already connected in `script.js`. The booking page also includes a direct-open fallback button.
